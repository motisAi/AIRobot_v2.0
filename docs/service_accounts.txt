Service Accounts & API Keys
===========================

Picovoice Porcupine
-------------------
Purpose : Wake-word detection (custom "Gonzo" keyword)
URL     : https://console.picovoice.ai
Steps   :
 1. Create a free account.
 2. Generate an access key and set it in the `.env` file under `PICOVOICE_ACCESS_KEY`.
 3. Build a custom Porcupine keyword for "Gonzo" (English, high sensitivity).
 4. Download the `.ppn` model into `data/models/wake_word.ppn`.

OpenAI
------
Purpose : Cloud LLM for intelligent dialogue (online mode).
URL     : https://platform.openai.com
Steps   :
 1. Create an account and generate an API key.
 2. Store the key in `.env` as `OPENAI_API_KEY`.
 3. Set `AI_PROVIDER=openai` in `.env` (this is the default).
 4. The AIEngine uses the `gpt-4o-mini` model by default.

Anthropic Claude
----------------
Purpose : Alternative cloud LLM provider (online mode).
URL     : https://console.anthropic.com
Steps   :
 1. Create an account and generate an API key.
 2. Store the key in `.env` as `ANTHROPIC_API_KEY`.
 3. Set `AI_PROVIDER=anthropic` in `.env`.
 4. The AIEngine uses `claude-3-haiku-20240307` by default.

Hailo Developer Zone
--------------------
Purpose : Hailo-8/8L SDK, firmware, and pre-compiled model files (HEF).
URL     : https://hailo.ai/developer-zone/
Steps   :
 1. Register for a developer account.
 2. Download the HailoRT SDK `.deb` packages for aarch64.
 3. Download YOLO HEF models from the Hailo Model Zoo.
 4. Place HEF files in `data/models/` (e.g. `yolov8s.hef`).

Offline LLM (GGUF Models)
--------------------------
Purpose : Local LLM inference when no internet is available.
URL     : https://huggingface.co (search for GGUF models)
Steps   :
 1. Download a GGUF model (e.g. TinyLlama, Phi-2, or Mistral 7B quantized).
 2. Place it anywhere accessible and set `OFFLINE_MODEL_PATH` in `.env`.
 3. Install `pip install llama-cpp-python` to enable the backend.
 3. Optional: Activate Riva/TAO if you want to experiment with NVIDIA speech stacks.

Optional Accounts
-----------------
- **Hologram / Twilio Super SIM** – required only if you plan to use the SIM7600X LTE modem.
- **Cloud messaging (Firebase/AWS SNS)** – useful when you expose remote notifications from `ServerConnectivity`.

Keep this file updated whenever you add a dependency that requires registration so future deployments remain frictionless.
